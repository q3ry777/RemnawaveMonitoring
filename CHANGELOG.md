# Что нового

## 2026-11-12
- Настройки бота переехали в сам бот: команда /settings (или кнопка «⚙️ Настройки», только главный админ) — уведомления, тихие часы, автопроверка из РФ, статус сервиса, пользователи, оплата (тарифы и реквизиты), дополнительные админы. Применяются сразу, без команды установки. В программе остались только подключения бота. Порядок обновления: сначала обновите бота (cd /opt/remnawave-bot && docker compose pull && docker compose up -d) — он сам перенесёт прежние настройки из .env, потом при необходимости заново скопируйте команду установки.

## 2026-11-11
- Бот: кнопка «📡 Статус сервиса» для пользователей с Telegram ID в панели — состояние нод под публичными названиями, отдельный блок «недоступны из России» и сбои за 7 дней. Пользователям ничего не рассылается. Сбой можно скрыть из статуса кнопкой под тревогой или командой /hide. Включается в настройках → telegram-бот → «статус сервиса для пользователей» (после этого заново скопируйте команду установки).

## 2026-11-10
- Автопроверка доступности нод из РФ (check-host.net) по расписанию — в программе и в боте. Интервал задаётся в настройках («автопроверка из РФ» и в разделе «telegram-бот»), 0 — выключена. Тревога — когда нода стала недоступна из РФ или доступна лишь частично, и сообщение, когда снова доступна; смена подтверждается повторной проверкой. Для бота после обновления заново скопируйте команду установки.
